# apps/web

Rules for the React PWA. The root `CLAUDE.md` still applies.

- **Web auth (`apps/web/src/lib/api.ts`):** the access token lives in a module variable only — never localStorage/sessionStorage. The session is restored on load from the refresh cookie. All refreshes go through `refreshSession()`, which is single-flight in the tab and wrapped in a `navigator.locks` lock across tabs: two concurrent refreshes with the same cookie would trip the API's reuse detection and revoke every session. Never call `/auth/refresh` directly.
- **Web data:** server state via TanStack Query hooks in `src/lib/queries.ts`. Request bodies are validated client-side with the same `@shortlist/shared` schemas the API uses. Response types are hand-written in `src/lib/types.ts` (dates as ISO strings). Verification is never optimistic — the UI shows "verified" only after the server confirms.
- **Web styling:** use the semantic color tokens (`bg-surface`, `text-muted`, `bg-apply-bg`, … from `apps/web/src/index.css`) and the primitives in `src/components/ui.tsx` — never raw Tailwind palette colors (`slate-500`), or dark mode breaks. Icons from `lucide-react`. Mobile design (Agents.md §8.4.1): primary buttons are the green accent (`bg-accent text-on-accent`); style a navigating link as a button with `buttonStyles()`; overlays use `Sheet` (native `<dialog>`), never a hand-made modal; screen-to-screen pushes go through `PushLink` / `pushNavigate()` (`lib/navigation.ts` — react-router's `viewTransition` prop does nothing under `<BrowserRouter>`); swipe gestures keep `touch-action: pan-y pinch-zoom` so scrolling and pinch-zoom stay native; appearance (System/Light/Dark) is `lib/theme.ts` + the pre-paint script in `index.html` — dark tokens must stay under both the media query and `[data-theme='dark']` in `index.css`; page titles use `PageHeader` (it carries the phone's account button, so page tests mock auth with `vi.mock('../auth/AuthProvider', () => import('../test/signed-in'))`). Job list state belongs in the URL (`useListState`), not component state. To hide a component responsively, wrap it — a `hidden` class on an element whose own classes set `display` (e.g. Button's `inline-flex`) loses.
